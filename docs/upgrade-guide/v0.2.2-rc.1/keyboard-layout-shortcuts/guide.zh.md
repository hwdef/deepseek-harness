# 快捷键跟随当前键盘布局

[English](guide.md) | 中文

## 变更

可配置命令现在匹配当前键盘布局打出的字符，而不是物理键位。绑定仍以 US 布局的 code 声明、保存和显示，因此 `⌘N` 依然显示为 N，而在 Dvorak、Colemak、AZERTY、德语等所有拉丁布局上，按 `⌘` 加打出 `n` 的那颗键即可执行。US QWERTY 行为不变。

由此产生三个可见影响。打出绑定字符的键即使位于别的位置也会触发该命令，原来的位置不再触发；已保存的自定义绑定保留原有 code，因此在非 QWERTY 布局下录制的绑定现在表示该 code 对应的字符；不产生映射字符的按键仍按物理键位匹配，包括死键、输入法组字、非拉丁布局、小键盘数字，以及输入框的 `/` 和 `@` 等固定序列。

## 迁移

1. 在使用非 US 布局的设备上打开「设置 → 通用 → 键盘快捷键」，检查含义已变化的自定义绑定。
2. 重新录制受影响的操作，然后用打出对应字符的那颗键按一次显示的组合键确认。
3. 检查需要 `Shift` 才能打出字符的命令，例如德语布局的 `/` 或 Dvorak 的 `,`：按实际使用的修饰键重新录制，或直接按下组合键核对录制结果。
